# Релиз 0.29.0 — самолёты научных баз и тематические наборы

## Самолёты

- Добавлены пять отдельных иллюстраций самолётов с разными силуэтами: пассажирский джет, многомоторный электрический самолёт, арктический турбопроп, лунный космоплан и экспериментальный перехватчик.
- Самолёты доступны на отдельной полке магазина, показываются в ангаре и «Моём мире»; для каждого тематического самолёта настроены оттенки тюнинга.
- Самолёт каждого научного стиля добавлен в соответствующий набор: «Атом», «Импульс», «Полярный» и «Луна».

## Наборы и баланс

- В тематическом наборе теперь четыре части: база, машина, самолёт и костюм. Покупка добавляет все части, а цена учитывает только то, чего ещё нет у ученика.
- Премиальная цена набора составляет три суммы стоимости недостающих частей.
- Стоимость ядерной базы и редкости тематических костюмов согласованы с категориями соответствующих научных баз.

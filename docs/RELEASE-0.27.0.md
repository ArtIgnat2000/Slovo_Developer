# Релиз 0.27.0 — тип каждой вещи: обычный, крутой, легендарный, ТОПОВЫЙ

## Что изменилось

- Каждой вещи магазина назначен тип. Тип определяется ценой в кристаллах:
  - **обычный** — до 30 💎;
  - **крутой** — 31–60 💎;
  - **легендарный** — 61–85 💎;
  - **ТОПОВЫЙ** — от 86 💎.
- Тип виден в карточке магазина (бейдж в углу), в подробном листе (под названием), в ангаре и на вкладке «Мой мир».
- Фон вещи зависит от типа: обычный — серый, крутой — голубой, легендарный — фиолетовый, ТОПОВЫЙ — золотой. Цвет есть на карточке магазина, у вещи в ангаре, на слоте и в списке «Моего мира».
- На вкладке «Мой мир» типы идут по возрастанию: обычный → крутой → легендарный → ТОПОВЫЙ (внутри типа — по цене). Это касается и слотов, и списка выбора.
- Тип не меняет цену, покупку, тюнинг и выбор ребёнка. Старые профили не мигрируются.
- Вручную тип задаётся полем `rarity` у вещи в `src/engine/shop.ts`; без поля действует правило по цене.

## Проверки

`typecheck`, `test:smoke` (тип каждой вещи, границы по цене, порядок по возрастанию, бейдж и фон по типу на «Моём мире»), `build`, `test:adaptive`, `content:check`, `test:boot`.

# Релиз 0.28.0 — научные базы и машины в их стиле

## Научные базы

- В каталоге зданий оставлены четыре базы: ядерная, электронная, арктическая и лунная; иллюстрации остальных зданий удалены.
- Ядерная и лунная базы отмечены редкостью **ТОПОВЫЙ**, электронная и арктическая — **Легендарный**. Метки видны в магазине и при выборе базы мира.
- В «Моём мире» база задаёт отдельный фон и не занимает ни одно из трёх мест для обычных вещей.

## Машины

- Добавлены четыре детализированные машины, каждая в стиле своей базы: «Квант», «Импульс», «Полярник» и «Луноход».
- Для машин подключены иллюстрации, описания, редкости по соответствующим базам и палитры тюнинга.

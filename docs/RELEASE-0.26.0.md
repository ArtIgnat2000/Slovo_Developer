# Релиз 0.26.0 — ангар: одна большая картинка и выбор части

## Что изменилось

- «Ангар БУКа» — одна большая сцена. Сверху показана выбранная часть целиком:
  - **полка для телефона** — телефоны стоят на деревянных полках;
  - **пристань для корабля** — корабли у причала, море и волны;
  - **гараж для машины** — машины в гараже с лампами.
- Под сценой выбор части из трёх (переключатель, как в магазине). У каждой части видно, сколько вещей в ней стоит.
- Сцена открывается на части любимой вещи. Если любимой нет, — на первой части, где есть покупки.
- Пустая часть на сцене подсказывает, что туда встанет после покупки.
- Любимая вещь отмечается звездой ★ и показывается крупнее. Тап по вещи ставит или снимает звезду, как раньше.
- Техника по-прежнему не рисуется на БУКе, профиль не меняется, данные не мигрируются.

## Проверки

`typecheck`, `test:smoke` (выбор частей, сцена по любимой вещи, пустые подсказки), `build`.

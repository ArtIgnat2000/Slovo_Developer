# Релиз 0.26.0 — ангар из трёх частей

## Что изменилось

- «Ангар БУКа» теперь состоит из трёх частей, в этом порядке:
  - **Полка для телефона** — телефоны стоят на деревянных полках;
  - **Пристань для корабля** — корабли у причала, море и волны;
  - **Гараж для машины** — машины в гараже с лампами.
- Каждая часть видна всегда. Пустая часть подсказывает, что туда встанет после покупки.
- Любимая вещь отмечается звездой ★ в своей части и показывается крупнее. Тап по вещи ставит или снимает звезду, как раньше.
- Большой подиум сверху убран: отдельного блока вне трёх частей в ангаре больше нет.
- Техника по-прежнему не рисуется на БУКе, профиль не меняется, данные не мигрируются.

## Проверки

`typecheck`, `test:smoke` (включая три части ангара и пустые подсказки), `build`.

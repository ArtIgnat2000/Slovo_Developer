# Релиз 0.25.0 — стартовые 100 000 алмазов и всё открыто

## Что изменилось

- Новый профиль начинает с **100 000 алмазов** (`STARTING_GEMS` в `src/state/store.ts`).
- С первого запуска открыто всё: каждая вещь магазина (наряды и техника, включая
  новые модели телефонов, ноутбук, телевизор и наушники), все 10 костюмов с полными
  фрагментами, все мелодии и наборы звуков, все дополнительные оттенки вещей и
  костюмов, все облики сундуков. Выбор по умолчанию не меняется: стартовая мелодия,
  классика, базовый облик сундука, без надетых вещей.
- Старые профили из хранилища получают открытое один раз при загрузке (флаг
  `openedAll`). Алмазы, покупки, надетые вещи и выбранная музыка сохраняются.
- Импорт файла резервной копии ничего не открывает: в копии остаётся её собственное
  состояние покупок.
- Сброс профиля создаёт новый профиль, в котором уже всё открыто.
